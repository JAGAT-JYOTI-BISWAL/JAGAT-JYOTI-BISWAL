01 · 🧠 Context-Aware Intelligence System — RAG

«A retrieval-augmented AI backend built to make the difference between direct LLM generation and context-grounded generation observable.»

Stack: Python · FastAPI · MongoDB Atlas · Hugging Face · Groq API · Render

""GitHub" (https://img.shields.io/badge/GitHub-Repository-064d3b?style=flat-square&logo=github&logoColor=64ffda)" (https://github.com/JAGAT-JYOTI-BISWAL/context-aware-intelligence-system-python)
 
""Live" (https://img.shields.io/badge/Live-Render-064d3b?style=flat-square&logo=render&logoColor=64ffda)" (https://context-aware-intelligence-system-python.onrender.com)

What it demonstrates

- Built two answer modes: direct LLM generation and retrieval-augmented generation for comparing grounded and ungrounded responses.
- Generated semantic embeddings with BAAI/bge-small-en-v1.5.
- Implemented manual cosine-similarity retrieval over MongoDB-stored knowledge entries.
- Selected top-K relevant context before answer generation.
- Designed structured prompting and response generation through Groq.
- Added fallback handling for malformed model responses.
- Organized the FastAPI backend into router, schema, service, repository, and utility layers.
- Added validation, centralized error handling, seed-based demo data, and Render deployment.

"RAG" "FastAPI" "Embeddings" "Semantic Retrieval" "LLM Integration"

<br/>02 · 📊 Smart Learning Analytics — End-to-End ML System

«An end-to-end machine-learning system that transforms educational activity data into a deployable student-classification pipeline.»

Stack: Python · FastAPI · scikit-learn · Pandas · NumPy · Joblib · Docker · Render

""GitHub" (https://img.shields.io/badge/GitHub-Repository-1a0533?style=flat-square&logo=github&logoColor=bd93f9)" (https://github.com/JAGAT-JYOTI-BISWAL/smart-learning-analytics)
 
""Live" (https://img.shields.io/badge/Live-Render-1a0533?style=flat-square&logo=render&logoColor=bd93f9)" (https://smart-learning-analytics-6cxe.onrender.com)

What it demonstrates

- Built an end-to-end ML pipeline using the xAPI-Edu-Data educational dataset.
- Aggregated 10.6M+ VLE clickstream rows and 173.9K assessment records into a clean per-student classification dataset.
- Engineered features across engagement, assessment, demographic, and registration signals.
- Resolved a real schema mismatch through dataset inspection and joins with assessment CSV data.
- Trained and compared Logistic Regression, Random Forest, and Gradient Boosting using 5-fold stratified cross-validation.
- Selected Random Forest as the best-performing model.
- Achieved approximately 0.882 CV F1, 0.900 test accuracy, 0.877 F1, and 0.972 ROC-AUC.
- Reused the same feature-engineering logic during training and inference to prevent training-serving skew.
- Exposed the final model through a lightweight FastAPI prediction service.

"Machine Learning" "Feature Engineering" "Model Evaluation" "FastAPI" "Deployment"

<br/>04 · 🔐 Secure Contact Management System

«A secure multi-user Spring Boot REST API focused on authentication, authorization, ownership isolation, and clean layered architecture.»

Stack: Java 17 · Spring Boot 3 · Spring Security 6 · Spring Data JPA · PostgreSQL · JWT · Maven · Docker

""GitHub" (https://img.shields.io/badge/GitHub-Repository-2d0b1a?style=flat-square&logo=github&logoColor=f48fb1)" (https://github.com/JAGAT-JYOTI-BISWAL/secure-contact-manager-java)
 
""Live" (https://img.shields.io/badge/Live-Render-2d0b1a?style=flat-square&logo=render&logoColor=f48fb1)" (https://secure-contact-manager-java-u7qw.onrender.com)

What it demonstrates

- Built secure multi-user contact management with JWT-based stateless authentication.
- Used BCrypt for password hashing.
- Enforced per-user data isolation through service-layer ownership validation.
- Prevented unauthorized read, update, and delete operations with appropriate "403 Forbidden" responses.
- Structured the backend using controller, service, repository, entity, DTO, security, and exception layers.
- Implemented paginated, searchable, and sortable contact listings.
- Added centralized JSON error handling for "400", "401", "403", "404", and "409" responses.
- Persisted application data using PostgreSQL and Spring Data JPA.

"Spring Security" "JWT" "BCrypt" "Authorization" "JPA" "PostgreSQL"
